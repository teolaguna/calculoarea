# CALCULOAREA - Calculadora de Area Modular

Actividad 3: Enfoque Modular y Diseno Top-Down en C++.

## Estructura

```text
/calculoarea/

├── LICENSE
├── README.md
├── docs/
```

## Requisitos

- Windows 10/11
- g++ (MSYS2/MinGW) o OnlineGDB
- VS Code (opcional)

## Comandos para ejecutar

```
g++ src/main.cpp -o src/area.exe
.\src\area.exe
```
